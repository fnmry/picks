Settings

Where you bet

Best price picks the cheapest of the places you tick, fees included. A sportsbook can win it for comparison; Overlay still buys on Kalshi or Polymarket US.

Unit size

One unit is what you put on a 1U pick.

3U at 85 in 100 and up, 2U at 70 to 84, 1U at 55 to 69, and half a unit below that. Stakes follow how likely a pick is, not any edge over the price.

Auto-bet on Kalshi

Takes effect at the laptop's next refresh, within about 75 minutes. To stop this second, double-click stop-autobet in the overlay folder (and resume-autobet to undo it).

  1. What to tail

    Tap a sport to tail its top picks. Each tile shows how those picks have done in paper at $10 a unit.

  2. Connect Kalshi

    How to connect

    Your keys never go in this page. They stay on your laptop.

    1. On kalshi.com, open Account, then API keys, and create a key. Kalshi shows a Key ID and gives you a key file.
    2. In the overlay folder, C:\Users\finnm\overlay, double-click set-kalshi-key.
    3. Paste the Key ID. Then paste the key, or drag the key file into the window. It saves both and asks Kalshi for your balance, so you know it works.

    Or run the same thing in a terminal in the overlay folder:

    uv run python -m overlay.executor keys

    To practise with play money first, make the key at demo.kalshi.co and add --demo to that command.

  3. Set your unit and limits

    • Run it on your laptop

      In .env, set the mode: EXECUTION_MODE=paper to practise at real prices with nothing sent, demo for Kalshi's play money, or live for real money. Then, in a terminal in the overlay folder:

      uv run python -m overlay.executor

      It lists each order and your Kalshi balance, then waits for you to type place.

      To let it bet by itself, add this line to .env. Your laptop then runs it every 30 minutes from 10am to 11:30pm Eastern while it's on, sends each order without asking, and writes every run to .data\executor\auto.log. Delete the line to go back to asking.

      AUTO_CONFIRM_LIVE=yes

      To stop everything at once:

      uv run python -m overlay.executor stop
